# 甜途 Demo · UI 评审与修复记录

> 评审日期：2026-11-15 · 评审对象：`甜途移动端UI重构Demo-v2.html` / `travel-ui-redesign.html`
> 评审视角：移动端 UI/UX 与可访问性（不评价原有界面是否“好看”，只处理可用性、层级、触控与一致性问题）

## 一、评审结论

整体方向成立：樱花粉主调 + 糖果撞色、五栏底部导航、3D 图标使用克制，业务流程没有断裂。本轮没有改变业务功能，只修复了会直接影响可用性、可读性和可信度的问题。

## 二、发现的问题与修复

### P0 · 阻断级

1. **新建旅程 / 旅程详情底部操作栏跑到屏幕外**
   - 现象：375×812 下，新建旅程 CTA 的 `y=952`，固定栏 `y=939`，用户看不到提交按钮。
   - 原因：`.screen` 的入场动画使用 `transform: translateY()`，为内部 `position: fixed` 创建了包含块，固定栏相对整页高度定位。
   - 修复：入场动画改为纯透明度过渡；抽出统一的 `.bottom-bar` 组件。
   - 验证：固定栏 `y=739`、`bottom=812`，CTA 完整可见；375 / 430 / 500 三种宽度均居中且不超出 430px。

2. **底部固定区遮挡最后一段内容**
   - 修复：`.has-actionbar` 预留 92px；列表页 `.screen` 预留 88px；表单增加 `scroll-padding-bottom: 120px`。
   - 验证：首页、我的、旅程详情、新建旅程滚动到底后，最后内容均位于固定栏上方。

### P1 · 可读性与触控

3. **文字对比度不足**
   - 旧值：`#B08D99` 在 `#FFF6F8` 上仅 **2.78:1**；`#C94F73` 仅 **4.08:1**；白字在 `#E76F91` 上仅 **2.97:1**。
   - 新值：辅助文字 `#82606C`（5.16:1）、主色文字 `#B83F63`（5.04:1）、主按钮渐变 `#C04569 → #B83F63`（白字 4.89–5.34:1）。
   - 同步修正蜜桃、蜂蜜、薄荷、危险色等强调文字。

4. **字号过小**
   - 9px / 10px 元信息合计 69 处，12px 正文 23 处。
   - 修复：9/10px → 11px；正文 12px → 13px；列表副标题、提示、空状态说明提升到 12–13px；底部导航 11px。

5. **触控区域不足**
   - 旧值：`.btn-sm` 36px、`.seg-btn` 36px、`.chip` 34px、`.action-pill` 38px、部分文本链接仅 18px 高。
   - 修复：按钮 / 分段控件 / chip / 行动胶囊 / 文本链接统一到 **44px** 最小触控高度；行程操作按钮 36 → 44px。
   - 验证：全路由扫描仅剩原生 checkbox 本身 16px，其 label 触控区为 44px。

6. **深色模式局部失效**
   - 白色底按钮在深色模式下使用浅粉文字，几乎不可读；足迹地图、画册纸页、统计数字存在对比度问题。
   - 修复：增加 `--rose-on-white` 固定深玫红；地图卡片增加深色版本；画册纸页使用固定纸面文字色；统计数字增加深色 token。
   - 验证：axe-core 在 18 个页面 × 明暗双主题、10 个弹层 × 双主题下均无对比度违规。

### P1 · 可访问性

7. **图标按钮缺少可访问名称、弹窗缺少名称、搜索框缺少 label**
   - 修复：为照片、行程、搜索、通知、分享、空间、画册、返回、关闭、翻页等按钮补齐 `aria-label`；为 sheet / dialog / 照片查看器 / 翻页画册补齐 `aria-label`；搜索框增加可读标签。
   - 验证：26 个路由 + 主要弹层扫描，未命名按钮 / 输入框 / 弹窗均为 **0**。

8. **键盘与焦点**
   - 增加 `:focus-visible` 焦点环；打开 sheet 自动聚焦第一个输入框，关闭后归还焦点；`Esc` 关闭弹层；底部导航增加 `aria-current="page"`；切换类控件增加 `aria-pressed`。

### P2 · 流程与信息层级

9. **新建旅程的“1 去哪 / 2 什么时候 / 3 记录”是伪步骤**
   - 实际是单页表单，步骤条永远停在 1。
   - 修复：移除伪步骤，改为“基本信息 / 同行与空间 / 封面”三组卡片，并增加一句填写说明；移除进入页面自动弹键盘的 `autofocus`。

10. **首屏信息密度低**
    - 旅程详情 hero 308px，首屏只剩统计和 tab；故事详情 hero 320px。
    - 修复：旅程 hero 264px、故事 hero 278px，让“下一站 / 作者与正文”进入首屏。

11. **重复入口与伪地图**
    - 旅程页同时有顶部“旅行画册”按钮和底部画册区，入口重复；点阵地图却写“看地图 / 按省份查看”。
    - 修复：移除重复按钮；地图改为不可点击的“足迹示意”，保留“查看足迹”唯一入口；看板增加“点大小代表照片数量”说明。

12. **看似可点但无响应的元素**
    - 时间线里的“回忆”卡片是死按钮；故事作者行里的“关注”是嵌套在导航按钮里的假按钮；预算“清空”只弹 toast。
    - 修复：回忆卡改为非按钮容器；作者导航与关注按钮拆开；预算清空、行程删除、花销删除、加一天、碎碎念删除确认均改为真实交互；翻页画册从静态页改为 3 页可翻、可切换日间/夜间主题。

13. **表单错误只弹 toast**
    - 修复：字段级红框 + 行内错误文案 + 自动聚焦 + 输入后即时清除；新增目的地必填、日期必填、结束日期不得早于开始日期、金额 / 预算 / 邮箱 / 验证码等校验。

14. **日期输入在 375px 下溢出卡片**
    - 修复：`.sheet-form-grid` 改为 `minmax(0,1fr)`，输入框增加 `min-width:0`；实测结束日期右边界从 361px 收回到 338px（卡片内容区右边界 339px）。

15. **顶部安全区**
    - `pageHeader` 增加 `env(safe-area-inset-top)`，避免刘海屏 / 灵动岛遮挡标题与返回按钮。

## 三、验证结果

| 项目 | 结果 |
|---|---|
| 页面 / 宽度组合 | 26 路由 × 3 宽度 = 78 views，控制台错误 0，横向溢出 0 |
| axe-core | 18 页面 × 明暗双主题 + 10 个弹层 × 双主题，0 对比度 / 名称 / label 违规 |
| 未命名交互元素 | 0 |
| 触控扫描 | 仅原生 checkbox 16px（其 label 44px），其余均 ≥44px |
| 固定操作栏 | 375×812 下 `y=739`、`bottom=812`，CTA 可见 |
| 核心交互 | 记录回忆、切 tab、记花销、点赞、评论、解锁相册、新建旅程全部通过 |
| 图标 | 空 SVG 0；3D WebP 全部加载；`prefers-reduced-motion` 下动画 0 |
| 画册 | 3 页翻页、首尾禁用、夜间主题切换通过 |
| 数据操作 | 清空预算显示“未设置预算”、无 NaN；加一天 6→7；删除碎碎念需确认 |
