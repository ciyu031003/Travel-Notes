# v1.29.1 发布说明（build 61）

> 发布日期：2026-10-27 ｜ 主题：**移动端安全区修复与旅行圈公开页稳定性**

## 亮点

1. **修复旅行圈公开文章崩溃**：补齐虚拟列表缺失的数据源，并将移动端 hero 与剩余文章列表拆分渲染，避免公开 feed 出现空列表、重复文章或整页错误。
2. **统一移动端顶部安全区**：旅行圈、公开详情、骨架态、失败态、同步中心和后台移动顶栏统一使用系统 safe-area inset 加页面间距，状态栏不再压住软件内按钮和文字。
3. **补强公开页错误处理**：公开详情按 404、401/403、网络错误与服务端 5xx 展示对应状态；路由级错误兜底和列表局部 ErrorBoundary 避免单点异常扩散到整页。
4. **增加移动端确定性门禁**：新增 route-only Playwright 用例，覆盖 320/412px 视口与 24/32/44px 状态栏高度，以及公开 feed、单篇、404、503 场景。
5. **Android 原生壳锁定竖屏**：避免系统旋转导致安全区和移动布局在运行中切换。
