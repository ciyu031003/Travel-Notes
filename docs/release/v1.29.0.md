# v1.29.0 发布说明（build 60）

> 发布日期：2026-10-24 ｜ 主题：**结构收敛与基础设施**（P-13 跨端收敛 / 自建崩溃上报 / OTA 灰度回滚 / 旅行圈虚拟列表 / shadow 对齐）。
> 同日第二波：接续 v1.28.0（移动端全面修复），把评审 deferred 清单全部收口。

## 亮点

1. **P-13 跨端收敛**：旅行列表数据层下沉 `useTravelList()`；`<MobileOnly>/<DesktopOnly>` 声明式断点包装；相册解锁面板单一实现（文案漂移结构性根除）。`useTravelDetail` 经核实**不抽取**（详情页数据已单源，决策记录在改动记录）。
2. **自建崩溃上报上线**：`ClientErrorLog` 表 + `POST /api/diagnostics/client-error`（匿名可报、IP 限流、字段有界）+ 站主查询/清理端点；客户端全局 error/unhandledrejection + ErrorBoundary 三源上报（sendBeacon、同错误去重、会话限额）。线上 JS 白屏从此可观测。
3. **OTA 灰度与回滚 runbook**：`docs/ops/OTA-灰度与回滚.md`——分批放量（`APP_ROLLOUT_PERCENT`）与两种回滚场景（版本指回 / `APP_MIN_SUPPORTED_BUILD` 封杀）成为可执行流程。
4. **旅行圈移动端真虚拟列表**：react-virtuoso（仓库首个虚拟化依赖），滚过的卡片卸载、占位保留；桌面保持瀑布流。
5. **shadow-sm → shadow-xs 全站对齐**：v3 设计意图回归（39 处；变量名不动），决策记入 UPGRADE-EVALUATION §8。
