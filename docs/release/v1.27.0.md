## 1. Tailwind CSS 4.3.3（视觉零回归迁移）

- 依赖：`tailwindcss` 3.4 → **4.3.3**、新增 `@tailwindcss/postcss` 4.3.3；`postcss.config.js` 只保留 `@tailwindcss/postcss`（Lightning CSS 内建前缀，移除 autoprefixer 配置）。
- `app/globals.css`：`@import "tailwindcss"` 替代旧 `@tailwind base/components/utilities`；`@config "../tailwind.config.js"` 保留 P2-31 三层 token 与既有 theme；`@plugin "@tailwindcss/typography"`、`@custom-variant dark`、preflight 差异回填（border-color / placeholder / button cursor）。
- 5 个 `@apply` 块中 3 个含变体的块改写为普通 CSS（容器类 sm/lg media query、`.card`），2 个无变体块保留。
- **验收**：新增 `tests/e2e/visual.spec.ts`（8 页 × 390×844、固定时间/随机数/动画，`maxDiffPixelRatio 0.001`）先于升级落地；升级后 **8/8 通过**，其中 5 页 0px 差异、login/download/me 仅 ≤0.00072 的亚像素渲染差（无布局位移）。

## 2. 多副本部署就绪

- **可选 Redis（`REDIS_URL`）**：ioredis 6；未配置时行为与改造前完全一致（内存实现），配置后 → 跨副本共享限流（34 处调用迁移，key 维度/limit/window/响应 body 不变）与缓存（命令失败自动回退内存并告警一次）。
- **共享临时目录 `MEDIA_TMP_DIR`**：图片分片、视频分片、转码共用，避免多副本各写各的 `os.tmpdir()`。
- **feed 一致性**：推荐流缓存改走 `CacheService`（tag `social-feed`，TTL 60s），发布/取消公开、点赞/收藏/评论/屏蔽、post 改标/分享/取消分享后立即失效；未配 Redis 也消除「自己刚写完还看到旧数据」。
- 部署方式与剩余外部项见 `docs/ops/多副本部署.md`；单副本无需任何新环境变量，保持默认即可。
