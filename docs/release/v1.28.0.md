# v1.28.0 发布说明（build 59）

> 发布日期：2026-10-24 ｜ 主题：**移动端全面审查与修复**（登出收口 / 媒体幂等 / 返回导航 / 弹层返回键 / 键盘与低端机适配 / OTA 完整性）。
> 依据：2026-10-18 评审报告逐条复核 1.27.0 现状 + 全仓 13 类移动端 bug 模式扫描（全程 file:line 取证）。

## 亮点

1. **堵住离线创作丢失的次路径**：「我的」tab 抽屉登出此前不停同步引擎——401 会把尚未上传的离线创作批量打成 DEAD；现在两处登出走同一 `performLogout()`（停引擎 → 清库删媒体 → 清账号作用域 → 注销会话）。
2. **照片弱网重传不再重复**：相册媒体 POST 与分片 complete 接入 Idempotency-Key（与既有 5 个创建端点同款 `withIdempotency`），客户端透传队列幂等键。
3. **返回导航三连修**：深链兜底 push→replace + 应用内栈校正（修"返回又弹回详情"）；EdgeSwipeBack 去掉 6 处页面级重复挂载（修"一滑退两层"）；ChinaMap 补手势豁免（修"地图横拖被滑走"）。
4. **9 个全屏弹层接上硬件返回键**：编辑旅行故事/星图/旅行档案/照片留言/翻书模式等按返回先关弹层，不再整页退出丢输入。
5. **Android 15 (targetSdk 36) 适配补强**：评论输入行补底部安全区；低端机（deviceMemory/核心数 ≤4）运行时降级常驻玻璃模糊；BottomSheet 基座统一键盘避让。
6. **OTA 完整性收口**：size 快校验落地（进度条不再可能恒 0%）、安装前重验 SHA-256、版本号单一来源改为 build.gradle（漏配环境变量不再可能烘焙旧版本）。
