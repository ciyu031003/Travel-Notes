## 二、验收清单（逐项打勾）

### 1. 壳离线（断网可开）

- [ ] 断网状态冷启动 App，可打开首页（本地 webDir 壳）
- [ ] 断网状态可浏览本地相册（/album 纪念相册区显示本地缓存）
- [ ] 断网状态可浏览本地旅行列表（/travel 显示本地缓存）
- [ ] 断网状态可浏览本地碎碎念（/moments 时间线显示本地缓存）
- [ ] 断网状态可打开本地旅行留言页（/travel/[slug]/record）

### 2. 离线写（D-4 首期范围）

- [ ] 断网新建旅行 → 本地出现 + ↑ 角标 → 联网自动上传云端
- [ ] 断网新建相册 → 本地出现 + ↑ 角标 → 联网自动上传云端
- [ ] 断网写留言 → 本地保存 + 提示「联网后自动上传」→ 联网自动上传
- [ ] 断网发碎碎念 → 本地保存 + 提示 → 联网自动上传
- [ ] 断网添加照片（拍照/相册选图）→ 本地落盘 + ↑ 角标 → 联网自动 multipart 上传（C1）
- [ ] 上传后 sha256 去重：重复照片不产生重复记录

### 3. 同步引擎

- [ ] 联网启动自动同步（SyncEngine bootstrap）
- [ ] 网络恢复自动触发同步（onNetworkChange）
- [ ] 同步中心（/sync）准确显示：待上传/上传中/失败数量
- [ ] 失败项指数退避重试；可单个/全部重试
- [ ] 断网重连后无数据丢失或重复

### 4. 权限（3.6 三档）

- [ ] 移动端无 /admin 入口
- [ ] 各模块管理入口（旅行/相册/碎碎念）按能力显隐
- [ ] OWNER/MEMBER/VIEWER 三档：服务端写接口复检（VIEWER 403）
- [ ] 权限回归复用 B5 一次性脚本法（测完清理）

### 5. Web 不回归

- [ ] 桌面 Web 登录/相册/旅行/碎碎念/后台正常
- [ ] Web 端离线写不走原生管线（isNativePlatform=false 时在线直写）
