## 一、评审总评

方案的方向正确，可直接采纳的核心原则有：

- **70% 保留 / 30% 重构**，不做大换血
- 不做普通 SaaS、不模仿小红书，坚持「真实旅途记录 + 旅行故事发现 + 轻社交」
- 地图是旅行记录的入口，而不是「地图 + Marker」
- 互动克制：旅行记录感 > 社交媒体感

但方案撰写时未对照当前代码，**约六成问题断言已与现状不符或已被 UI-V3 解决**；同时**当前最大的两个真实缺口（触摸手势缺失、地图左右面板在移动端遮挡）方案完全没有识别**。详见下文逐条核实。

### 2.2 方案有效、但方案漏掉/未点名的真实问题（重点）

1. **触摸交互完全缺失（最大缺口，方案 §4.2 误以为已存在）**
   `ChinaMap.tsx` 只有 `onMouseDown/Move/Up + wheel`，全项目无任何 touch/pointer 手势处理。
   实况：移动端单指拖动与页面滚动打架（无 `touch-action`、无 preventDefault），**双指缩放完全不可用**，地图只能靠 +/− 按钮。方案写「保留 touch drag / pinch zoom」——实际从未实现过。

2. **左右可收起面板在移动端默认展开并遮挡地图（方案 §2.1.2「控制组件覆盖地图两侧」的真实来源）**
   `TravelClient.tsx`：`leftOpen/rightOpen` 默认 `true`，左右两个 `w-64` 面板（轮播 + 旅行信息）绝对定位覆盖移动端地图两侧。360px 视口下地图可视区仅剩约 100px，几乎不可用。方案把这归因于「地图控制组件」，实际是侧面板。

3. **ZoomControls 三件套移动端仍全部展示**
   `100%` / `滚轮缩放 · 拖拽移动` / `1:1` 在 ≤768px 依旧渲染，遮挡且无意义（方案 §4.1 正确，未实施）。

4. **MapLegend / ProvinceCityPanel 在移动端形态不佳**
   - 图例 `bottom-4 right-4` 在 40vh 小地图上占空间；
   - `ProvinceCityPanel` `w-[min(380px,100%)]` 右侧滑入，移动端满宽覆盖整个小地图，空间局促，更适合底部抽屉。

5. **旅行圈标签无任何交互**：`THEMES` 的 `onClick={() => {}}`，点了没反应。

6. **/travel 页底部无底导留白**：`MobileBottomNav` 为 fixed，`TravelClient` 内容区无 `pb`，页脚可能被遮挡（/circle 有 `pb-24`，/travel 没有）。

## 三、可借鉴到外部端（桌面端 ≥768px）的清单

以下移动端方案中的通用设计，桌面端同步受益（多数只需在共享组件上做一次）：

1. **卡片叙事信息架构**：`谁 → 和谁 → 去了哪里 → 什么时候 → 发生了什么 → 留下了什么`。
   现有 `SocialFilmCard` 已有地点/日期/天数/照片数/作者/互动，缺「和谁」——数据已存在（`Travel.travelType/companions`），补上后移动端桌面端同享（M8）。
2. **标题可读性规范**：图片上文字一律配底部渐变遮罩，不靠文字阴影。hero 已符合，可作为卡片统一规范沉淀。
3. **地图 z-index 纪律 + pointer-events 检查**：方案 §6 的层级表可作为全端文档规范（当前已符合，保持）。
4. **触摸板双指缩放**：M1 做 Pointer Events / ctrlKey+wheel 支持后，桌面触控板也能双指缩放地图——桌面端此前同样不可用。
5. **「探索旅途」文案**：比「为你发现」更包容（情侣/朋友/家人/独旅），全端统一（M6）。
6. **地图 → 旅行记录入口流**：地点 → 旅行 → 照片 → 文章，桌面已实现（ProvinceCityPanel/CityModal）；移动端底部抽屉形态（M5）可作为桌面窄窗口的参考。
7. **互动克制原则**：只保留 ♡ / 💬 / 收藏三项，不做转发关注分享——产品层规则，两端一致。

## 四、执行计划（P0 / P1 / P2）

### P0 —— 行迹地图移动端可用性（必须）

**M1 触摸手势支持（核心）**
- 文件：`components/ChinaMap.tsx`
- 改动：容器加 `touch-action: none`（地图区不抢页面滚动）；新增 touch 手势——单指 pan（复用现有 offset 状态）、双指 pinch（距离比值 → scale，围绕双指中点）、tap 保留省份/城市点击；wheel 保留并支持 `ctrlKey+wheel`（桌面触控板 pinch）。
- 验收：360/390/412 三档可拖动、可双指缩放、省份可点；地图外区域滚动正常。

**M2 地图控制层移动端精简**
- 文件：`components/china-map/ZoomControls.tsx`、`MapLegend.tsx`
- 改动：`100%` / 滚轮提示 / `1:1` 仅 ≥md 渲染；+ / − 按钮移动端缩至 w-8 h-8；图例移动端只显示圆点（隐藏文字）；控件层 z-40 → z-20（确保不盖 panel / 抽屉）。
- 验收：360px 下地图四角无遮挡浮层。

**M3 左右面板移动端策略**
- 文件：`app/travel/TravelClient.tsx`
- 改动：按视口初始化（≥768 默认展开；<768 默认收起）；收起态在移动端提供紧凑胶囊入口（照片 / 足迹）或直接 `md:block` 隐藏（见待确认 2）。
- 验收：移动端地图区域无覆盖；桌面端默认展开不变。

**M4 /travel 底部留白**
- 文件：`app/travel/TravelClient.tsx`
- 改动：内容区补 `pb-24 md:pb-0`，页脚不被底部导航遮挡。
- 验收：/travel 页脚完整可见。
