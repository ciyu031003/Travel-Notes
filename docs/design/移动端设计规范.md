# 移动端设计规范（单一事实源）

> 本文件是移动端 UI 的**唯一约定来源**。新增/修改 UI 前先读这里；规范与代码冲突时，以本文件为准并修正代码。
> 落地基线：P0（设计地基 + 图标体系）已完成。配套检查脚本见 `scripts/check-design-tokens.mjs`。

---

## 1. 设计原则

**Clear · Premium · Effortless**

| 原则 | 判断标准 |
|---|---|
| **Clear** | 首屏一屏内能说清"这是什么、我有什么、下一步做什么"；一屏只有一个视觉最重元素 |
| **Premium** | 高级感来自**留白、字阶、层次与材质**，不来自渐变、彩色与装饰 |
| **Effortless** | 主操作在拇指区；全 App 只有一个强主色按钮；不需要学习 |

**硬性纪律（违反即不合规）**

1. 界面上彩色面积占比 ≤ 15%，且只出现在：主 CTA、激活态、关键数字、内容图。
2. 禁止硬编码 hex/`rgba()`，一切颜色走 token。
3. 除 loading 外，禁止无限循环动画。
4. 一个页面最多 2 个大标题级别。
5. 图标只用 `Icon` 组件，尺寸只 3 档、描边只 2 档。
6. 触达目标 ≥ 44×44。
7. 禁止用字符（`✦ ✨ ✍ ★` 等）冒充图标。

## 2. 色彩

### 2.1 中性层（承载 90% 界面）

| Token | 浅色 | 用途 |
|---|---|---|
| `--m-bg` | `#FFFBF7` | 页面底 |
| `--m-bg-soft` | `#FFF3E9` | 暖色底（空态、占位） |
| `--m-surface` | `rgba(255,255,255,.82)` | 玻璃面 |
| `--m-surface-solid` | `#FFFFFF` | 卡片 |
| `--m-surface-2` | `#F7F3EF` | 次级填充 |
| `--m-text` | `#3D2B20` | 主文字 |
| `--m-muted` | `#7D6754` | 次要文字（**5.10:1 ✅ AA**） |
| `--m-faint` | `#B9A897` | 最弱文字/装饰 |

> ⚠️ `--m-muted` 曾为 `#9A8574`（3.36:1，不达标），已修正。不要改回去。

### 2.2 强调层

`--m-accent` `#C67A4E`（陶土）是**唯一强调色**。`--m-accent-strong` `#A85F3A` 为其文字态。
`--m-accent-soft` 用于浅底。

### 2.3 暖色色板（仅用于图标/内容，不用于界面框架）

`--m-sun` `#E4B478`（暖黄）· `--m-blush` `#F3C6B5`（腮红）· `--m-clay` `#B4705C`（深陶）

### 2.4 徽标色调（`IconBadge` / `Pill` 专用）

| tone | 背景 token | 前景 token | 浅色前景 |
|---|---|---|---|
| `accent` | `--m-tone-accent-bg` | `--m-tone-accent-fg` | `#A85F3A` |
| `sun` | `--m-tone-sun-bg` | `--m-tone-sun-fg` | `#A96C22` |
| `blush` | `--m-tone-blush-bg` | `--m-tone-blush-fg` | `#A85F4A` |
| `clay` | `--m-tone-clay-bg` | `--m-tone-clay-fg` | `#8A4A2B` |
| `neutral` | `--m-tone-neutral-bg` | `--m-tone-neutral-fg` | `#7D6754` |

### 2.5 语义色

`--m-success` `#3F8F62` · `--m-warning` `#B8801F` · `--m-danger` `#C0453F`

### 2.6 禁止

- ❌ 直接写 `bg-[#F7E6D9]` / `style={{ color: '#A8C8DC' }}`
- ❌ 新增渐变（已有渐变仅保留主 CTA 一处，且不得叠动画）
- ❌ 用彩色表达"分类"（分类用暖色 tone，不用冷色）

## 3. 字阶（7 档，唯一事实源）

| 类名 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `.m-display` | 32 / 38 | 700 | 首页唯一大标题 |
| `.m-title-1` | 24 / 30 | 700 | 页面标题（`LargeTitle`） |
| `.m-title-2` | 18 / 24 | 650 | 区块标题、卡片标题 |
| `.m-body` | 15 / 22 | 400 | 正文（默认） |
| `.m-caption` | 13 / 18 | 400 | 辅助说明 |
| `.m-label` | 11 / 14 | 600 | 英文眉标（字距 0.08em） |
| `.m-stat` | 32 / 32 | 700 | 统计数字（tabular-nums） |
| `.m-tab-label` | 11 / 14 | 500 | Tab 栏标签（**无字距**，中文专用） |

**规则**
- 一个页面最多 2 个大标题级别（通常 `m-display` 或 `m-title-1` + `m-title-2`）。
- 英文眉标字距统一 `0.08em`。**不要用 0.24em**（小屏上用力过猛）。
- 中文标签不要套 `.m-label`（其字距是为拉丁字母设计的），用 `.m-tab-label` 或 `.m-caption`。
- 所有数字展示统一 `tabular-nums`，避免数据变化时宽度跳动。

## 4. 间距 / 圆角 / 阴影

### 4.1 间距（4pt 基准，8pt 主节奏）

允许值：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`

| 类名 / Token | 值 | 用途 |
|---|---|---|
| `.m-gutter` | 20px | **页面横向内边距统一值**（不再混用 16/20/24） |
| `.m-safe-top` | `max(20px, env(safe-area-inset-top))` | 顶部安全区（不再混用 26/30/40/48） |
| `--m-section-gap` | 32px | 区块间垂直间距 |

### 4.2 圆角（4 档）

`--m-radius-card` 20px · `--m-radius-control` 14px · `--m-radius-pill` 999px · `--m-radius-sheet` 24px（仅顶部两角）

> 禁止 `rounded-[22px]` 这类魔术数字。

### 4.3 阴影（2 档 + 发丝线）

| Token | 用途 |
|---|---|
| `--m-shadow-l1` | 卡片（极轻） |
| `--m-shadow-l2` | FAB / Dock / Sheet / Toast |
| `--m-hairline` | 列表分隔、Tab 顶边 |

> 禁止组件内自写 `shadow-[...]`。

## 5. 图标体系 ⭐

### 5.1 唯一入口

```tsx
import { Icon } from '@/components/mobile/Icon'

<Icon icon={MapPin} />                                  // md / 继承文字色
<Icon icon={Route} size="sm" tone="muted" />
<Icon icon={Heart} size="lg" tone="accent" label="纪念日" />
```

### 5.2 尺寸（仅 3 档）与描边（仅 2 档）

| size | 尺寸 | 描边 | 用途 |
|---|---|---|---|
| `sm` | 16px | 2 | 行内、Pill、Tag |
| `md` | 20px | 2 | **默认**：列表行、Tab、按钮内 |
| `lg` | 24px | 1.75 | 空态、Sheet 标题、Hero 图标 |

**规则**
- ❌ 禁止 `h-3` / `h-3.5` / `h-5` / `h-7` / `h-9` / `h-12` 之类自由取值。
- ❌ 禁止 `strokeWidth={1.6}` / `2.4`（历史上同屏出现 4 种粗细）。
- ✅ 需要更大视觉重量时，**放大容器**（`IconBadge`），不要放大图标。

### 5.3 色调

`inherit`（默认，currentColor）· `text` · `muted` · `faint` · `accent` · `inverse` · `success` · `warning` · `danger`

❌ 禁止裸 hex 上色、禁止为"好看"随意上彩色。

> ⚠️ **跨主题边界（迁移图标时的头号陷阱）**
> 项目存在 **4 套并行 token 体系**，取值并不相同：
> | 体系 | 强调色（浅色） | 用在哪 |
> |---|---|---|
> | `--m-*` | `--m-accent` `#C67A4E` | 移动端设计系统（默认） |
> | `--album-*` | `--album-accent` `#e8b06a` | 相册三模式（画册/银河/像素） |
> | `--social-*` | `--social-accent` `#A85F3A` | 旅行圈 / 我的 |
> | 像素主题 | `pixel-*` 系列 | 像素模式（直角、复古） |
>
> 在 `--album-*` / `--social-*` / 像素主题的组件里迁移图标时：
> **只归一「尺寸 / 描边」，保留原有的主题颜色类（`className="text-album-accent"` 等），不要改传 `tone`。**
> 传 tone 会把颜色静默切到 `--m-*` 体系（例：`#C67A4E` ≠ `#e8b06a`），造成不易察觉的变色。
> 只有当图标**自身**写死颜色且父容器无可继承色时，才用 tone（此时优先 `inverse`）。
>
> 长期看这 4 套体系应合并为 1 套（见 §10 第 4 项），届时本限制才可解除。

### 5.4 语义映射（去重）

| 语义 | 唯一图标 | 禁止混用 |
|---|---|---|
| 地点 / 城市 | `MapPin` | — |
| 地图 / 足迹 | `Map` | `MapPin` |
| 旅行（Tab） | `Route` | `MapPin` |
| 照片（单张） | `Image` | — |
| 画册 / 相册 | `Images` / `BookOpen` | — |
| 拍摄 | `Camera` | — |
| 纪念日 | `Heart` | — |
| 时间线 | `CalendarDays` | — |

| 通知 | `Bell` | 字符 `✦` |

### 5.6 使用方式

```tsx
// 图标 + 暖色圆润容器
<IconBadge icon={CalendarDays} tone="accent" />
<IconBadge icon={Volleyball} tone="blush" size="lg" shape="circle" />

// 语义标签（图标 + 文字）
<TravelTypePill type={travel.travelType} />
<ActivityPill kind="STROLL" />
<ItineraryChip type={it.type} locationName={it.locationName}>{it.title}</ItineraryChip>
```

## 6. 组件清单与选用

### 6.1 基础（`components/mobile/`）

| 组件 | 用途 | 关键约束 |
|---|---|---|
| `Icon` | 图标唯一入口 | 3 尺寸 / 2 描边 / token 色 |
| `IconBadge` | 图标容器 | 5 种暖色 tone；`squircle`/`circle` |
| `IconButton` | 图标按钮 | **保证 44×44**；必填 `label` |
| `Pill` / `TravelTypePill` / `ActivityPill` / `ItineraryChip` | 语义标签 | 暖色 tone + 图标 |
| `ListSection` / `ListRow` | 功能入口列表 | 统一行高 64 / IconBadge / 分隔线 |
| `StatBlock` / `StatRow` | 统计表达 | 数字走 `.m-stat` |
| `LargeTitle` | 页面大标题 | 24px（`m-title-1`） |
| `EmptyState` | 空态 | 图标 + 标题 + 说明 + **单一** CTA |
| `Skeleton` | 加载骨架 | 形状须匹配真实布局 |
| `BottomSheet` / `ActionSheet` | 面板 | 顶部圆角 24 |
| `SegmentedControl` / `Switch` | 选择控件 | 圆角 14 |
| `Toast` | 反馈 | 语义色 |
| `PullToRefresh` | 下拉刷新 | — |
| `Stagger` / `CountUp` / `MobilePageTransition` | 动效 | 见 §7 |

### 6.2 选用原则

- 需要"图标 + 标题 + 说明 + 箭头"的行 → `ListRow`，**不要自己拼 `m-card flex`**。
- 需要"图标 + 底色" → `IconBadge`，**不要再写 `bg-[#...]`**。
- 需要图标按钮 → `IconButton`，**不要写 `h-9 w-9`**。
- 需要语义标签 → `Pill` 系列。

## 7. 动效与触觉

| 项 | 规范 |
|---|---|
| 时长 | 交互反馈 120ms · 入场 320ms · 页面转场 240ms |
| 属性 | 只做 `opacity` + `transform`，不碰 layout 属性 |
| 无限动画 | ❌ 禁止（原 `m-fab-glow` 呼吸动画已移除） |
| 降级 | `prefers-reduced-motion` 全量降级（`.m-*` 动画全部关闭） |

**触觉分级**

| 级别 | 场景 |
|---|---|
| `hapticLight` | Tab 切换、卡片按压、列表点击 |
| `hapticSuccess` / `hapticError` | 登录、保存、解锁成功/失败 |

## 8. 可访问性

- 触达目标 ≥ 44×44（`IconButton` 已内建）。
- 文字对比度 ≥ 4.5:1（`--m-muted` 已修正）。
- 图标按钮必须给 `aria-label`；装饰性图标由 `Icon` 自动 `aria-hidden`。
- 焦点可见。

---

## 9. 合规检查

```bash
node scripts/check-design-tokens.mjs
```

检查项：
1. 硬编码 hex / `rgba()` 数量
2. 图标尺寸档位（是否出现非 3 档的 `h-N w-N` 配 lucide）
3. 直接 `import ... from 'lucide-react'`（应改走 `Icon`）
4. 非标字号（不在 7 档内）
5. 字符冒充图标（`✦ ✨ ✍ ★`）

---

## 10. 变更流程

1. 新增 UI 前确认本文件有对应规范；没有就先补规范。
2. 新增颜色/字号/圆角 → 先加 token，再使用。
3. 提交前跑 `npm run typecheck` + `node scripts/check-design-tokens.mjs`。
4. 桌面端零回归：所有移动端差异走 `md:` 断点或移动端独立分支。
