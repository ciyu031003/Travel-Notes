# 空间类型配色系统（清新淡雅 · 五套主题）研究报告

> 所有色值均来自具名开源调色板的具名色阶，或明确标注 **derived（自算推导）**。所有对比度由本文自行按 **WCAG 2.1 相对亮度**公式计算：对每个 sRGB 通道 `c/255`，`c ≤ 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`，再取 `L = 0.2126R + 0.7152G + 0.0722B`，比值 `(L_lighter + 0.05) / (L_darker + 0.05)`。

## B. 色相分配的理由（排序：依据强度递减）

1. **COUPLE = 薄荷绿**。绿色在中文语境里承载「长青 / 和睦 / 生机」，且**天然避开两处文化雷区**：红（已被品牌赤陶占用，且婚庆正红一旦低彩度化会显得脏）、白（丧仪）。绿是五色中唯一既吉祥又不与品牌色争夺注意力的色相。低彩度绿也是「情侣」品类最不容易显得幼稚的选择。
2. **FAMILY = 鸢尾紫**。中文「紫」= 紫气东来、贵气、祥瑞，且常与「家宅/长辈」的稳重感绑定；紫在东亚的正面度显著高于在西方（西方紫偶有「丧色」联想，中文语境没有）。选 iris 而非 plum：iris 蓝相更沉稳，适合家庭共享相册的「可信 / 归档」气质。
3. **FRIENDS = 天青蓝**。蓝=信任、开阔、旅途天空，是社交场景最安全的色相，也是唯一能在「活泼」与「淡雅」之间不越界的冷色。避免用黄/橙（与品牌赤陶同区，会稀释品牌）。
4. **SOLO = 梅紫**。独旅的语义是「向内、黄昏、自我对话」；plum 是五个色相中彩度感受最「低语」的一支，且与 iris 距离 27° + 明显明度差，不会串味。避免用灰蓝（会像「无主题」）与青绿（与薄荷撞车）。
5. **OTHER = 沙色**。fallback 的正确姿态是「安静、不主张」。sand 是暖中性且与 `#F7F4EE` 同族，彩度≈0，绝不会与其他主题争抢；避免再次引入彩色（否则 5 个主题里会出现两个含义不明的彩块）。

**文化禁忌清单（必须尊重）**：① 正红仅可用于节庆/婚庆内容与错误态，不作为空间主题色；② 白/纯白不作主题色与大面积底（丧仪），底仍用暖纸 `#F7F4EE`；③ 忌大面积深黑（暗色主题用 `#080808`/`#111111` 且面积受 §C 限制）；④ 绿帽联想要求绿必须**偏青/偏薄荷**、绝不可偏黄（黄绿＝橄榄，在中文语境有负面含义）。

## C. 五个主题如何不像五个 App

**允许随空间类型变化的令牌（仅 7 个，全部是色彩且全部低彩度）**：
`--space-accent`、`--space-accent-strong`、`--space-accent-soft`、`--space-accent-text`、`--space-on-accent`、`--space-hairline`、`--space-hero-a/b`。

**必须全局共享、禁止按空间覆写的令牌**：
`--bg #F7F4EE`、`--surface #FFFFFF`、`--surface-2`、`--text #2B211B`、`--text-muted`、`--border`、`--divider`、`--shadow-*`、`--radius-*`、`--space-*`（间距）、字体族与字号阶梯、`--brand-accent #A85F3A` / `--brand-accent-strong #8A4A2B`（品牌色在五个空间里**始终可见**：Logo、全局导航、设置页 CTA）。
**暗色共享**：`--bg #080808`、`--surface #111111`、`--brand #E8B36A`。

这套「变量少 + 中性层完全共享」的做法直接借用 [daisyUI 的主题变量模型](https://github.com/saadeghi/daisyui/discussions/1811)：一套语义变量 + 一个作用域选择器（`[data-space="COUPLE"]`），组件里零硬编码 hex。中性层不动，是「同一个 App」的锚点；只换 7 个低彩度变量，是「每种空间不一样」的全部来源。

**≤15% 彩色面积 · 每主题上线自检清单**：
1. 单屏内所有 `--space-accent*` 像素总和 ≤ 屏面积 15%（含 CTA、激活态、徽标、进度环）；
2. 彩色只出现在：主 CTA、激活态（tab/列表项/图标）、关键数字、内容图片；**不得**用于页面底、卡片底、列表分隔、段落文字色；
3. 每屏最多 1 个 `--space-accent-strong` 实心 CTA；
4. `--space-accent-soft` 仅作小面积标签/徽章底（单块 ≤ 屏 4%）；
5. hero 渐变仅限头图区（高度 ≤ 屏 35%），且渐变内文字一律用 `--space-accent-text`；
6. 品牌赤陶仍出现在全局层（Logo/导航/设置），保证切空间不丢品牌；
7. 暗色下 `--space-accent-soft` 面积上限下调至 8%（暗底上色块视觉权重更大）。
