## 1. 评审结论

两个模块此前都经过 1.16.x 的多轮建设：空间有完整的五套 Radix 配色主题体系（§2.8 受控多主题）、
旅行圈有 hero + 瀑布流叙事。本轮发现的问题集中在**交互诚实性与体系一致性**，共 10 项：

| # | 模块 | 问题 | 严重度 |
|---|---|---|---|
| C1 | 旅行圈 | **话题 chips 是假筛选**：「海边/周末旅行/摄影」的 `activeTheme` 从未接入取数逻辑，点了没有任何效果——误导用户的假 UI，违反规范「Clear」原则 | 高 |
| C2 | 旅行圈 | 手动「加载更多」无自动加载，长列表翻页成本高 | 中 |
| C3 | 旅行圈 | SocialFilmCard 无触摸按压反馈（只有桌面 hover 位移） | 中 |
| C4 | 旅行圈 | 3 处 `!important` 覆盖（`!rounded-[26px]` / `!h-11 !px-6 !text-sm`），违反规范 §2.6 第 10 条 | 低 |
| C5 | 旅行圈 | 日期区间显示原始 ISO（`2026-01-01 ~ 2026-01-05`），机械不中文 | 低 |
| S1 | 空间 | SpaceCard/详情行按压用孤立的 `active:scale-[0.995]`，未接入 P0-A 的弹簧体系 | 中 |
| S2 | 空间 | 退出空间用 `window.confirm` 浏览器弹窗——移动 WebView 上一眼"网页感" | 高 |
| S3 | 空间 | 列表页自绘 fixed toast，与全局 ToastHost 体系并行（两套观感） | 中 |
| S4 | 空间 | 详情页 hero 滚走后顶部空无一物，返回键随之滚出视口（P1-F 已给 LargeTitle 页做了折叠，空间详情是自绘 hero 没享受到） | 高 |
| S5 | 空间 | 相册封面无图时是纯色空块；所有图片占位色块→实图为硬切 | 低 |

## 2. 落地内容（对应编号）

### 旅行圈（feat(circle)，commit `9972bfb`）

- **C1 真实类型筛选**：
  - `listSocialFeed` 增加 `travelType` 参数——挂在关联 `Travel.travelType` 上过滤
    （legacy 无 Travel 的帖不匹配任何类型）；`recommended` 的 60s 热度缓存 key 追加
    `:t<type>`，避免不同筛选共享同一份候选集；无效值回落为不过滤；
  - `/api/social/posts` 透传 `travelType`；
  - 前端 chips 换为 `TYPE_FILTERS`（全部/独旅/与TA/与家人/与朋友/与闺蜜/结伴），
    样式统一 `m-chip` token；筛选导致空态时文案改为「这个类型下还没有故事」+「看全部」按钮，
    不再误导向"去发布"。
- **C2 无限滚动**：IO 哨兵（`rootMargin: 400px` 提前触发）自动加载下一页；手动「加载更多」
  保留兜底；底部状态行（加载中/到底了 · 共 N 篇）。
- **C3 卡片按压弹簧**：`m-card-pressable`（两相位），`m-card-pressable` 的 transition
  补齐 background-color/border-color 以免覆盖卡片 hover 渐变。
- **C4 `!` 覆盖清理**：骨架圆角走 inline style；空态/重试按钮换 `Button` 组件。
- **C5 日期格式**：同年省略年份（`1月1日 – 1月5日`），跨年带年份。

### 空间（feat(space)，commit `b26d4e5` + `eb42473`）

- **S1 按压统一**：SpaceCard 与详情旅行行/规划行走 `m-card-pressable`，相册格 `m-pressable`。
- **S2 退出确认**：`window.confirm` → `ActionSheet`（破坏性项红色 + 空间名标题）；
  结果走全局 toast（成功 info / 失败 error）。
- **S3 toast 收敛**：删除列表页自绘 fixed toast，统一走 `toast-store` + ToastHost。
- **S4 空间色折叠栏**：hero 滚出视口顶部时浮出 `.m-space-collapser`（返回 + 空间名 + 设置），
  配色走空间 token（`--space-hero-a` 底、`--space-hairline` 发丝线、`--space-accent-text` 文字）；
  `@supports (color-mix)` 时 86% 半透明 + 毛玻璃，不支持实色兜底；IO 哨兵零 scroll 监听。
  这是全局 `.m-collapser` 的空间主题变体——**必须渲染在 SpaceThemeScope 子树内**。
- **S5 图片淡入**：新增通用 `.m-img-fade`（onLoad 加 `.is-loaded`，reduce-motion 直出）；
  相册封面接入，无图空态补主题色图标占位；空间详情页接入边缘右滑返回。
