## 2026-08-18 · Stage 0：基线审计

### 改动目标
为相册视觉升级建立代码基线，产出一份可执行审计清单。

### 主要发现

- rose 粉色系为活跃风格（应迁移到 travel 语义色）；notes 紫霓虹为死代码（已隔离）。

## 2026-08-19 · Stage 2.1/2.2：社交域 Schema + 公开权限

### 2.1 Prisma 社交域（prisma/schema.prisma）
- 新增 3 枚举：CommentStatus（VISIBLE/HIDDEN/DELETED/PENDING）、NotificationType（LIKE/COMMENT/REPLY/FAVORITE/FOLLOW）、ReportStatus（PENDING/REVIEWED/DISMISSED/ACTIONED）。
- 新增 8 模型：TravelPost（travelId 唯一）、PostLike、PostFavorite、Comment（parentId 自关联回复）、CommentLike、UserFollow（自关联）、Notification（read 列映射 isRead 避 MySQL 保留字）、Report。
- 唯一约束防重复互动：@@unique([postId,userId])、[commentId,userId]、[followerId,followingId]、[postId,reporterId]。
- 外键级联：删 Travel 删其 TravelPost，删 TravelPost 删其互动/评论/举报，删 User 删其社交内容。

### 2.2 公开权限模型
- 新增 lib/modules/social/social-permissions.ts：canReadTravel / canReadMedia / isPublishedToCircle（PRIVATE 仅自己 / COUPLE 我的 Space / PUBLIC 旅行圈，兼容旧 isPublic）。
- 新增 lib/modules/social/travel-post.service.ts：syncTravelPost（幂等 upsert/删除）、publishTravelPost、unpublishTravelPost、getTravelPostByTravelId、serializeTravelPost。
- 接入两处旅行服务（幂等、失败不阻断）：lib/modules/travel/space-travel.service.ts（RBAC 主路径）、lib/modules/travel/travel.service.ts（旧 isPublic 路径）的 create/update/delete。

### 2.3 迁移与回填
- scripts/apply-schema-migration.cjs 新增「社交域建表」段落：8 张表 CREATE TABLE IF NOT EXISTS + 外键/索引（幂等）。
- 新增 scripts/backfill-travel-posts.cjs：为存量 visibility=PUBLIC 或 isPublic=1 的旅行生成 TravelPost（幂等）。

### 验证
- npx prisma validate 通过；npx prisma generate 通过（v7.9.1）；npx tsc --noEmit 通过；两个 .cjs 脚本 node --check 通过。
- 说明：本地 MySQL 未启动（localhost:3306 ECONNREFUSED），建表在服务器 Docker 入口自动执行。
