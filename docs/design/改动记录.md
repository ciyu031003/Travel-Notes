## 2026-08-20 · 旅行星图升级：仿 3D 星盘 + 双指缩放

### 改动目标
将相册「星图」（像素模式顶栏入口，`app/album/page.tsx` 内 `TravelStarMap`）从静态平面 SVG 升级为可交互的仿 3D 星空星盘：可双指放大缩小、拖拽平移、点选城市。

### 实现（components/album/TravelStarMap.tsx 重写）
- 技术：Canvas 2D 伪 3D（轻量、无 WebGL 依赖，适配 Capacitor 移动端），rAF 渲染循环 + 后台暂停。
- 仿 3D 布局：经纬度投影到「绕 X 轴俯仰的倾斜星盘」（`TILT≈53°`），北侧远离视角产生近大远小透视；每座城市按照片数给「悬浮高度」，照片越多越浮起、越近、越大。
- 交互：双指捏合缩放（以两指中点为锚点）、单指拖拽平移（带惯性缓动）、滚轮缩放、双击复位、点选城市弹出信息卡；`touch-action:none` 防滚动冲突；键盘 +/- 缩放、方向键平移。
- 视觉：背景星点三层视差（透明度 ≤0.5）、城市星点光晕 sprite + 名称标签、按时间顺序的星际航线（缓慢流光）。
- 无障碍/性能：`prefers-reduced-motion` 冻结动画与惯性；DPR 自适应（≤2）；`role=img` + `aria-label` + `tabIndex`。
- 设计一致性：沿用 `--album-*` 暗色 token（背景 #050508 / 暖金 #e8b06a），星空只做点缀、金色克制、不引入霓虹/复杂渐变，信息卡复用 `space-glass` 玻璃样式。
