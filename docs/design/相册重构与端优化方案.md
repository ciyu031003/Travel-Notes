## 四、相册功能缺口（P1，待确认）

1. **画册墙 vs 单册（产品决策，最关键）**：
   - 现状：只显示 `books[0]`，数据存在多本（多城市/多 Travel）时其余不可见；
   - 选项 A：保持单册（对应 01:40 unify 意图：只留「上传图片生成的这一本」）；
   - 选项 B：恢复画册墙（`33dd7c4` 版本可局部恢复），点击单本再进翻页阅读器。
2. **`blurUrl` 完全未用**：`PostcardCard` 与 `ArtPage` 均无模糊占位，应补加载占位提升首图体验。
3. **内容页增强**：`chapter` 页未展示 itinerary / memories / mood；photoSpread 可选叠加记忆文案。
4. **`cqw` 容器查询单位**：老 WebView 兼容性需实机验证（低版本 Android WebView / 旧内核）。
5. **页码指示偏差**：`artPageIndex+1` 与 page-flip 双页展开可能有一页差，需修正。
6. **加载/空态/错误态统一**：`opening` 与 loading 文案重复；网络失败与空数据共用「重试」按钮，应区分处理。
