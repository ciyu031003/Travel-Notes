# 真机验证清单（1.28.0 / build 59）

> 背景：2026-10-19 起真机/模拟器验证一直被环境阻塞（无 Hypervisor、模拟器软件模拟无法 boot，
> 见 `真机验证报告-2026-10-19.md` §2），静态门禁（tsc/vitest/tokens/构建）全绿但**运行期行为从未在设备上核验过**。
> 本清单汇总：① 历来被阻塞的 7 项（按风险排序）；② 1.28.0 本轮修复项的验收步骤。
> 全部命令可直接复制（PowerShell；需要 adb + 一台 arm64 真机，Android 8–16 建议覆盖一台 Android 15+）。

## 0. 准备

```powershell
adb devices                                   # 确认设备已连接
adb install -r android/app/build/outputs/apk/release/app-release.apk
adb shell am start -n com.tiantu.app/.MainActivity
Start-Sleep 15
adb logcat -d | findstr /i "FATAL AndroidRuntime crash"   # 期望：空
```

## A. 历来被阻塞的高风险项（源自 10-19 报告 §6）

## B. 1.28.0 修复项验收

### B1 登出清理（P0）
1. 登录 A 账号 → 飞行模式 → 新建一本旅行（离线待同步）。
2. **从「我的」tab 右上角抽屉点退出登录**（本轮修复的次路径）。
3. 关飞行模式，不登录任何账号，等待 1 分钟。
4. `adb shell run-as com.tiantu.app ls databases/` 后用 debug 包查库行数，或直接观察：
   **期望**：不登录直接看 /travel 不显示 A 账号内容；重新登录**任意账号**后，同步中心不出现"无法同步 N 项"（离线那本旅行要么已在退出前上传、要么在 A 账号重新登录后继续上传——**绝不能凭空消失或出现在别人账号**）。

### B2 照片幂等（P0）
1. 登录 → 相册选图上传大图（>2MB 走分片）。
2. 用 `adb shell cmd connectivity airplane-mode enable`（或开关飞行模式）在**进度 90% 左右**断网，再恢复。
3. **期望**：相册里该照片只有一张（旧版会重传成两张）；同步中心最终"待上传 0"。

### B3 深链返回弹跳（P0）
1. 从通知/分享链接直接打开某条旅行详情（冷启动深链）。
2. 点页内返回 → **期望**落在旅行列表；再按系统返回 → **期望**继续退出（回首页/离开），**不能弹回刚离开的详情页**。

### B4 侧滑返回一滑一层（P0）
1. 首页 → 旅行 tab → 点开任意详情 → 左缘右滑。
2. **期望**：一次滑动只退一层（回到列表），不再跳两层回首页。同路径在「我的→账号设置」「旅行圈帖子详情」「空间详情」「通知」复测（这 5 处此前都双重挂载）。

### B5 地图手势（P0）
1. /travel 桌面入口（平板）或地图页：从地图**左缘 24px 内**横向拖动。
2. **期望**：只平移地图，整页不被"滑走"。

### B6 全屏弹层返回键（P1）
逐个打开下列界面后按系统返回键，**期望都是"先关弹层"而不是退出整页**：
- 画册：添加照片弹窗 / 旅行星图 / 城市旅行档案 / 照片留言视图 / 翻书模式（主题弹窗开着时先关主题弹窗）/ 银河模式（先退出银河回书墙，留言开着时先关留言）
- 地图：省份/城市半屏抽屉（选中城市先回省份列表）
- 旅行圈：举报弹窗 / 编辑旅行故事（编辑一半按返回不应丢内容——关弹层后内容还在表单里）

### B7 评论输入安全区（P1）
手势导航机型（无实体键）打开任意帖子评论抽屉：**期望**输入行不被手势条遮挡。

### B8 冷加载不闪桌面树（P1）
手机冷启动直接进某条旅行详情链接：**期望**先看到骨架（标题条+图占位），然后直接出移动版式；**不应**先闪一屏桌面文章式排版再翻转。/travel tab 切换应明显变快（不再加载桌面地图 chunk）。

### B9 低端机玻璃降级（P1）
在 deviceMemory≤4 或核心数≤4 的设备（多数千元机）：滚动旅行圈/列表。
**期望**：底栏为实心面板（无毛玻璃），滚动不掉帧。旗舰机不受影响（仍有毛玻璃）。

### B10 键盘避让（P1）
移动 Web（浏览器打开站点）+ 原生壳各测一遍：
- 同步中心 → 设置隐私锁 → 点 PIN 输入框：**期望**键盘弹出后 sheet/输入框仍可见（Web 端此前会被盖住）。
- 新建旅行表单拉到底：粘底"开始记录"按钮在键盘弹出时仍可见。

### B11 OTA 更新链路（P1）
1. 服务端发布 1.29.x（或测试 manifest）后，旧包启动 → 弹更新 → 下载。
2. **期望**：进度条正常走动（0% 卡死修复）；下载完成拉起安装器；**在系统安装器点取消 → 回 App 再点"继续安装"**：仍能安装（安装前重验通过）；若在文件管理器手动替换/损坏该 APK 再装：提示"安装包校验失败"。

### B12 规范类（P2，抽查即可）
- 同步中心统计卡为 2×2；"Sync"眉标字距变窄（0.08em）。
- 登录页"记住我"整行可点、热区明显变大；密码显隐按钮好点了。
- 隐私锁连错 5 次 PIN → 提示"失败次数过多，N 秒后可重试"，期间键盘禁用，倒计时结束恢复（**杀进程重开锁定依然生效**）。

## C. 回归基线

每轮 APK 合入前至少复测：登录 → 首页 → 旅行列表 → 详情 → 记一笔 → 相册翻页 → 旅行圈点赞评论收藏 → 同步中心 → 登出。观察 `adb logcat -d | findstr /i FATAL` 恒为空。
