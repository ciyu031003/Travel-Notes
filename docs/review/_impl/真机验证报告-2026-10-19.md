## 2. 环境阻塞详情（可复现）

### 2.1 根因：x86_64 模拟器需要硬件加速，本机未安装 Hypervisor

两个独立启动尝试都失败/挂死：

```text
$ emulator -avd lwb-smoke-35 -no-window -no-audio -no-snapshot
ERROR | x86_64 emulation currently requires hardware acceleration!
CPU acceleration status: Android Emulator hypervisor driver is not installed on this machine

$ emulator -accel-check
accel: 6
Android Emulator hypervisor driver is not installed on this machine
```

- 主机：Windows，15.74GB RAM（空闲 5.7GB），无 WHPX/AEHD/HAXM。
- `Get-WindowsOptionalFeature -FeatureName HypervisorPlatform` 返回 **"requires elevation"** —— 开启 Windows Hypervisor Platform 需要管理员权限 + 重启，按任务要求**不尝试**。
- 仅安装了 x86_64 系统镜像（`system-images/android-35/google_apis/x86_64`），没有 arm64 镜像可绕开加速。

### 2.2 `-accel off` 的实测结果：进程活着但 guest 不跑

按任务要求尝试了一次软件模拟（这是本机唯一可能绕开 Hypervisor 的路径）：

```text
$ emulator -avd lwb-smoke-35 -no-window -no-audio -no-boot-anim -no-snapshot -accel off -gpu off -memory 2048 -cores 2
（已先清理 AVD 残留锁 hardware-qemu.ini.lock / multiinstance.lock，否则会因"同一 AVD 多实例"直接退出）
INFO | WARNING: x86_64 emulation may not work without hardware acceleration!
...
netsimd ... （日志停在此处）
```

- 启动后 `adb devices` 出现 `emulator-5554  offline`（transport 建立、guest 未就绪）；
- 之后 15 分钟内 **`sys.boot_completed` 始终取不到**、`bootanim` 取不到；
- 关键证据：`Get-Process emulator` 的 **CPU 累计时间 = 0 秒**、工作集 13MB，日志在 21:36:11 后不再增长 → **QEMU 主循环没有跑起来**（不是"慢"，是"停"）。
- 结论：本机环境下软件模拟也不可用（emulator 37.1.11 在无 accel 的 x86_64 目标上不可用）。

日志证据：`docs/review/_impl/evidence/emulator-start-attempt.log`、`emulator-start-attempt.stderr.log`、`emulator-accel-check.txt`。


## 6. 待真机验证清单（按风险排序）

1. **SQLite 明文库 → 加密库迁移（C1 最高风险）**：装 1.24.8 并登录写数据 → 覆盖装 1.25.0 → 启动 → 确认不白屏、数据在、`databases/` 下库文件非 `SQLite format 3` 明文头、且迁移备份文件 `db-upgrade-backup.json` 已删除（成功）或保留（失败回滚）。
2. **覆盖升级后本地数据保留**：升级前后 `/data/data/com.tiantu.app/files` 与 databases 行数对比（可用 debug 包 + run-as）。
3. **冷启动隐私锁**：设 PIN → 杀进程 → 冷启动出现全屏键盘；错 PIN 拒绝、对 PIN 放行；Web 端不出现。
4. **Release 包 R8 生效后的运行时兼容**：SQLCipher 建库、Camera 拍照、Haptics、AppUpdater 下载安装（keep 规则只能真机证实）。
5. **B5 压缩与分片**：拍照后队列 payload 无 thumbBase64、上传成功后原图消失而 `<id>-thumb.jpg` 保留；>2MB 图走 `/api/media/resumable`，中途断网恢复后只补缺失分片、失败回退整图。
6. **WebView 首屏**：冷启动是否白屏/闪白、是否成功加载 `https://travel-notes.yuanabd.cn/login`（本轮只能证明页面在包内 + API 基址正确）。
7. **单次启动无 FATAL**：`adb logcat -d | findstr /i "FATAL AndroidRuntime"` 应为空（本轮未执行）。
