# 相册粒子银河空间重构方案（参考 Mineradio）—— 360° 全景唱片银河版

> 状态：**待用户确认**

## 二、Mineradio 前端设计拆解（已通读源码）

Mineradio（`E:\浏览器下载\Mineradio-2.1.0`）是原生 JS + **Three.js r128 + ShaderMaterial + GSAP** 架构。核心可借鉴点：

### 2.1 背景星河（粒子银河旋臂）—— `public/js/modules/02-visual/00-pointer-cover-particles.js`

- `BACKGROUND_STAR_RIVER_COUNT = 1400`，`BufferGeometry` 仅 3 个属性：`aSeed / aLane / aDepthSeed`
- **顶点着色器**用 hash 随机构造旋转银河：
  - 6 条带（band）分层，`flow = fract(hash + uTime * speed)` 缓慢流动
  - `arc`（弧角）、`radius = 7.2 + bandN*15.8 + hash*6.2`（旋臂半径）、`wave`（波浪）
  - 冷色 `vec3(0.34,0.76,1.0) → vec3(0.60,0.44,1.0)` 与暖色 `vec3(1.0,0.78,0.58)` 混合
  - `twinkle` 闪烁、`ridge` 亮脊、`dust` 尘埃遮挡
  - `AdditiveBlending` 叠加、`gl_PointSize` 按深度衰减、`uAlpha` 淡入淡出

### 2.2 黑胶唱片粒子预设（VINYL RECORD）—— 本项目唱片视觉的直接参考

Mineradio 顶点着色器内置 **Preset 4: VINYL RECORD**，结构：
- 中心圆形区域 = 专辑封面粒子（`coverR = 1.18`，UV 映射到圆形内采样封面色）
- 外圈 = 黑色黑胶面，`groove` 同心圆槽纹（径向 sin 波纹，随 `uVinylSpin` 自转）
- 白色高亮 rim（`outerRim` 白边）、封面色晕染到黑胶内圈
- 粒子带 `uVinylSpin` 自转（`mat2(cs,-sn,sn,cs)` 旋转 2D 坐标）
- 高低分辨率保护：`hiResGuard` 在封面分辨率高时降低粒子抖动/槽纹

### 2.3 全景相机/轨道视角

- `public/js/modules/01-scene/01-orbit-free-camera.js`：**轨道相机**（拖拽旋转 yaw/pitch、滚轮缩放、双击回正、自由相机模式）
- `00-pointer-cover-particles.js`：鼠标 raycast 到粒子平面、涟漪交互
- 相机缓动与"居中回正"系统，全程平滑

### 2.4 UI 设计语言 —— `public/index.html` + `public/css/index.css`

- 深空暗色系（接近 `#050508`），动态高亮色 `--fc-accent` / `--fc-accent-rgb`
- **玻璃质感**：
  - `backdrop-filter: blur(12px) saturate(1.8) brightness(1.16)`
  - 内发光阴影：`inset 0 0 2px 1px rgba(255,255,255,.35)` 等
  - SVG 色散玻璃滤镜（`#mineradio-control-glass-filter`，RGB 三通道 displacement）——即"RGB Shift 玻璃"
- 胶囊形控制条（`border-radius:50px`）、悬浮 FX 面板、底部控制栏
- 字体：Cinzel Decorative（装饰）/ Inter（正文）/ JetBrains Mono（数字）/ Noto Sans SC

## 三、目标设计（提示词 → 实现映射）

### 3.1 背景层：银河（360° 包裹）

| 提示词要求 | 实现 |
| --- | --- |
| ShaderMaterial 程序化星云（Perlin/FBM 多层噪声） | 大球壳（SphereGeometry 内表面）ShaderMaterial：3 层 FBM 噪声 + 旋转旋臂 + 色带，**随相机 360° 环视永远包裹全场** |
| 星点粒子系统（BufferGeometry + Points） | 移植/改写 Mineradio `backgroundStarRiver` 着色器：星点分布在**以相机为球心的大球壳/圆柱壳**上（约 1600 粒子，旋臂 + 冷暖色 + 闪烁） |
| 深空黑底 `#050508` | 场景 clear color / CSS 底 `#050508` |
| 远景星点缓慢漂移 | `uTime` 驱动 flow（低速） |

> 由于相机可 360° 转动，背景必须"贴"在相机上（skybox 球壳挂在 camera 下）或做成大球壳场景包裹，保证任何视角都有银河。

### 3.2 照片粒子化

| 提示词要求 | 实现 |
| --- | --- |
| Canvas 2D 读像素 → 每像素一个 Points 粒子 | 照片先缩到 ≤160px 采样，按步长抽取；每张照片按扇形扇区映射到唱片表面（中心封面 + 外圈照片环） |
| 粒子位置 = 像素坐标 + 随机 Z（±2.0） | `aRand` 映射 `depth = (aRand-0.5) * 4.0`（聚合态 z 偏移），形成立体厚度 |
| 粒子颜色 = 原始 RGB | 整张照片作为 `THREE.Texture`，着色器 `texture2D` 取色（Mineradio 方式，内存省、可做渐变）；备选 `aColor` 属性直接写 RGB |
| 大小随亮度动态调整 | `aBright`（灰度）驱动 `gl_PointSize` 乘数 |
| ShaderMaterial + `uProgress` 散落↔聚合 | `uniform float uProgress`：0=随机球面散落（切换/取消选中时粒子飞离唱片），1=聚合为唱片上的照片/封面；`smoothstep` 过渡 + 缓动 |
| `sizeAttenuation` 远景缩小 | `gl_PointSize = size * uPixel * scale / max(0.5, -mv.z)` |

### 3.3 3D 空间布局（360° 全景银河轨道）

| 提示词要求 | 实现 |
| --- | --- |
| 图片放在银河 3D 背景里 | 每个城市一张粒子黑胶唱片，**悬浮在银河空间中**：唱片沿环形轨道绕中心（相机默认位置）一周排布，半径 14~18，分 2~3 层高度错开，朝向圆心 |
| 360° 全景视角 | **相机位于环中心**，拖拽 = yaw 0~360° + pitch 上下俯仰（限制 ±60°），任意方向都能看到对应唱片；银河背景全程包裹 |
| 滚轮上下来回滑动 | 滚轮 = 切换城市唱片（上一张/下一张），相机平滑转向目标唱片正面；特写状态滚轮 = 放大缩小 |
| 360° 旋转 | 每张唱片**唱机式自转**（槽纹 + 封面粒子旋转，Mineradio `uVinylSpin` 思路）；拖拽唱片可加速/反向，特写可翻转看背面 |
| 放大缩小 | 点击唱片 = 相机拉近进入特写；特写中滚轮 = 缩放；任意状态 Ctrl+滚轮 / 触控板捏合 / HUD 按钮 |
| 鼠标视差 | 相机根据 pointer 轻微偏移（lerp 平滑），强化景深 |
| 选中唱片 `uProgress→1`，其他散开+降透明度 | 选中唱片粒子 `uProgress→1`；未选中唱片维持低亮度、透明度降低，退到银河背景中 |
| 镜头缓动 | 手写 lerp / GSAP：yaw 最短路径转向目标唱片 θ 角 + 拉近距离 + `lookAt` 唱片中心 |

### 3.4 交互

| 操作 | 行为 |
| --- | --- |
| 拖拽（任意处） | **360° 全景环视**：左右拖 = yaw 转动（0~360°），上下拖 = pitch 俯仰（±60°），带惯性 |
| 鼠标悬停 | 唱片轻微上浮 + 边缘粒子呼吸；HUD 显示城市名/日期预览 |
| 滚轮 上/下 | 全景模式：切换城市唱片（上一张/下一张），相机平滑转到目标唱片正面；特写模式：放大/缩小 |
| 点击唱片 | 选中 → 相机拉近进入特写：粒子完全聚合、停止飘散，显示玻璃信息面板（城市/日期/张数/EXIF/「留言」按钮） |
| 特写中拖拽唱片 | 唱片 360° 自转加速/反向 + 翻转看背面 |
| Ctrl+滚轮 / 捏合 | 任意状态缩放 |
| 双击 / Esc | 特写 ↔ 全景 切换 |
| 留言按钮 | 进入粒子化留言页（`PhotoChatView`） |

## 四、唱片（Vinyl）视觉设计

### 4.1 唱片结构（每个城市一张，粒子构成）

```
┌─────────────────────────────┐
│  白色 rim 高亮环（外缘）      │
│  ┌───────────────────────┐  │
│  │  照片环：该城市全部照片   │  │
│  │  以扇形扇区排列在唱片面   │  │
│  │  （每张照片 = 一个扇区，  │  │
│  │   粒子径向采样填充）      │  │
│  │  ┌─────────────────┐   │  │
│  │  │ 中心封面：城市代表  │   │  │
│  │  │ 照片/首图，圆形粒子  │   │  │
│  │  │ 聚合 + 城市名/日期  │   │  │
│  │  │ 粒子文字标签        │   │  │
│  │  └─────────────────┘   │  │
│  │  · 黑色槽纹区            │  │
│  └───────────────────────┘  │
│  背面：黑胶反光 + 城市印记    │
└─────────────────────────────┘
```

- **中心封面区**：圆形粒子照片（Mineradio VINYL `coverR` 思路），城市名 + 日期用粒子文字/贴图
- **照片环扇区**：每张照片分配一个角度扇区（`angle = index / count * 2π`），照片粒子按极坐标（r、θ）径向采样映射到扇区内；照片多时自动分内外两圈
- **黑胶槽纹**：`r²` 递增的同心圆 sin 波纹（`groove`），随自转滚动产生反光闪烁
- **白色 rim**：外缘高亮粒子环
- **唱片背面**（可选）：深色黑胶粒子 + 中心标签（城市名/张数/日期），特写翻转可见
- **粒子来源**：全部照片缩略图 Canvas 采样，粒子颜色 = 像素 RGB

### 4.2 唱片动画状态机

| 状态 | uProgress | 行为 |
| --- | --- | --- |
| 全景轨道（未选中） | 0.35 | 粒子呈唱片形状但偏暗、透明度低，慢速自转 + 悬浮漂移 |
| 悬停 | 0.35 + 呼吸 | 上浮 + 边缘粒子飘散 |
| 选中（特写） | 1.0 | 粒子完全聚合、清晰、停止飘散，自转继续（唱机感） |
| 切换城市 | 旧唱片 → 0.15 | 粒子散开飞离 + 透明度降低；新唱片 → 1.0 聚合 |

### 4.3 全景轨道排布

- 唱片总数 = 城市数（一般 ≤ 30）；按 θ = index / count * 2π 均匀分布在环形轨道
- 高度按 2~3 层正弦错开（`y = layerHeight + sin(θ*2)*offset`），避免前后遮挡
- 每张唱片 `lookAt` 圆心（正面朝中心），用户转视角即可逐一浏览
- 当前选中唱片保持在正前方，其余在左右/上下视野边缘弱化（透明度 + LOD）

## 七、核心着色器设计（关键思路）

### 7.1 唱片粒子 vertex shader（示意）

```glsl
attribute vec2  aUv;        // 照片 UV
attribute float aRand;
attribute float aBright;
attribute float aEdge;      // 1 = 边缘/rim 粒子
attribute float aZone;      // 0=中心封面 1=照片环 2=槽纹 3=rim
uniform float uProgress;    // 0 散落 → 1 聚合为唱片
uniform float uHover;
uniform float uTime;
uniform float uVinylSpin;   // 自转角度（360° 无级）
uniform float uRimR;        // 唱片半径

void main() {
  // —— 聚合态：唱片表面极坐标 ——
  float r, theta;
  if (aZone < 0.5) {                    // 中心封面：圆形
    r = aUv.x * uRimR * 0.42;
    theta = aUv.y * 6.2831853;
  } else if (aZone < 1.5) {             // 照片环扇区：按照片索引分扇区
    float sector = floor(aRand * 12.0); // 示例：12 张照片扇区
    theta = (sector + aUv.x) / 12.0 * 6.2831853;
    r = mix(uRimR * 0.42, uRimR * 0.94, aUv.y);
  } else if (aZone < 2.5) {             // 黑胶槽纹
    r = uRimR * (0.42 + pow(aUv.x, 2.0) * 0.52);
    theta = aUv.y * 6.2831853 + uVinylSpin;
  } else {                              // 白色 rim
    r = uRimR * 0.985;
    theta = aUv.x * 6.2831853;
  }
  theta += uVinylSpin;                  // 唱机自转
  vec3 vinyl = vec3(cos(theta) * r, sin(theta) * r, (aRand - 0.5) * 0.6);

  // —— 散落态：随机球面 ——
  float phi = aRand * 6.2831853;
  float th  = acos(1.0 - 2.0 * fract(aRand * 7.13));
  float R   = 2.2 + fract(aRand * 3.7) * 3.2;
  vec3 scatter = R * vec3(sin(th) * cos(phi), sin(th) * sin(phi), cos(th));

  // 过渡
  float p = smoothstep(0.0, 1.0, uProgress);
  vec3 pos = mix(scatter, vinyl, p);

  // 悬停呼吸 + 边缘飘散
  float breath = sin(uTime * 2.0 + aRand * 6.28) * 0.04;
  pos += vinyl * breath * uHover;
  pos.z += aEdge * uHover * (0.15 + fract(aRand) * 0.35) * (1.0 - p);

  vec4 mv = modelViewMatrix * vec4(pos, 1.0);
  gl_PointSize = (1.0 + aBright * 2.2) * uSize * uPixel / max(0.5, -mv.z);
  gl_Position  = projectionMatrix * mv;
}
```

> 照片颜色：`vColor = mix(defaultColor, texture2D(uPhotoTex, aUv).rgb, uHasPhoto)`；槽纹区用黑胶色 + 反光。

### 7.2 背景银河 vertex shader（示意，移植 Mineradio 思路，相机球心分布）

```glsl
attribute float aSeed, aLane, aDepthSeed;
uniform float uTime, uAlpha;
void main() {
  float bandN  = (floor(aLane * 6.0) + 0.5) / 6.0;
  float flow   = fract(hash(aSeed) + uTime * (0.002 + bandN * 0.003));
  float arc    = (flow - 0.5) * 6.28 * (0.68 + bandN * 0.46) + bandN * 2.4;
  float radius = 40.0 + bandN * 80.0 + hash(aSeed) * 30.0;   // 大球壳半径，相机在内部
  float yaw    = (flow - 0.5) * 6.28 + bandN * 2.4;
  vec3 pos = vec3(cos(yaw) * radius, (bandN - 0.5) * 60.0, sin(yaw) * radius);
  // 冷暖色混合 + twinkle + dust，AdditiveBlending；粒子挂在 camera 下保证 360° 环绕
}
```

### 7.3 双粒子 Bloom 层

- 同一几何体 + 同一顶点着色器，`gl_PointSize *= 1.4`，片元用 `tex.a * tex.a` 软化 + `AdditiveBlending`，透明度约 0.5——直接复刻 Mineradio `bloomMaterial` 模式。

## 八、性能预算

| 项 | 桌面 | 移动 |
| --- | --- | --- |
| 背景银河粒子（球壳环绕） | 1600 | 900 |
| 单张唱片粒子（中心封面+照片环+槽纹+rim） | ≤8000 | ≤3500 |
| 高密度唱片（正前方/特写） | 1~2 张全粒子 | 1 张 |
| 远景/背后唱片 LOD | 低密度版本（粒子数减 70%） | 同左 |
| 同屏唱片 | 3~5 张（含 LOD，环形分布） | 3 张 |
| 总粒子数上限 | ≤25000 | ≤12000 |
| DPR | ≤2 | ≤1.5 |
| Bloom 层 | 开 | 关 |
| 渲染暂停 | `document.hidden` 暂停 | 同左 |

- 照片纹理使用缩略图（≤320px 采样），不加载原图进 GPU。
- 每张照片按扇区采样，照片数多时自动分内外圈，保证粒子密度均匀。
- 背景球壳星云用低分辨率渲染（256 级噪声采样）保证移动端帧率。
- 无 WebGL / WebGL 崩溃 → 自动 pixel 模式。
- `ParticleImageBg`（2D 留言页背景）保留现有限流（3600 粒子、DPR 1.5），如体验 OK 可暂不升级 Three.js。
